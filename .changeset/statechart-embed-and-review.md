Add `<autoviz-statechart>`, a web component that embeds an interactive statechart in any page. It takes the machine inline, from a URL, or from a ```statechart Markdown fence on pages that opt in. Walkthroughs with notes, autoplay and deep links tell a machine's story, and charts load as readers scroll to them. On phones the page scrolls past a chart and two fingers pan and zoom it.

Add a GitHub Action that reviews the XState machines a pull request changes, in code or MachineJSON. It posts one comment with a merge risk, the states and transitions added or removed, and a Mermaid statechart per changed machine.

Add SVG export, still or animated through a simulation, for READMEs and pull requests.

Restyle the app: resizable code, canvas and panel columns, a code-only view, larger labels, and event pills that sit on their lines.
