Embed charts on pages with a strict Content Security Policy, such as sandboxed iframes and Claude artifacts. `embed.js` carries its stylesheet and Geist fonts, and the layout measures labels with the same font stack the page draws, so state names and events fit with or without Geist. A button in the top-right corner shows the chart full screen. If a layout throws, the chart shows the error.
