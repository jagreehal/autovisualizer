Draw Mermaid state diagrams. Put a `stateDiagram-v2` in `<script type="text/mermaid">` inside `<auto-visualizer>`, open a `.mmd` file in the editor, or convert one to machine code with `cli.mjs mermaid diagram.mmd -o machine.ts`. Events, initial and final states, nested and parallel states and descriptions carry over.
